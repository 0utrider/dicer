# Plan 2 — rulings and deferred findings

This record comes from the controller ledger. Sign-off images were generated with `npm run test:visual`. Measurements are in docs/signoff/plan-2/signoff-measurements.md.

## Rulings
- ## Rulings
- Ruling P2-R1: programKey includes `interiorSteps` and the interior type/shape only when the interior is active (resin body && flags.interiors && interiorSteps > 0 && interior.type !== 'none'); otherwise the interior component is `none` — avoids duplicate programs and satisfies T6's equality test — cost if wrong: none.
- Ruling P2-R2: programKey's glow component is the boolean `flags.glow && glow.intensity > 0` (intensity itself stays a uniform) — DICER_GLOW changes the shader, so the key must reflect it; three also includes defines in its own cache key — cost if wrong: one extra program.
- Ruling P2-R3: physics hulls keep using the exact visual geometry (buildDieGeometry(shape) with defaults, now rounded). Task 2 must keep the full sim suite green, including the 50 ms first-chunk test; if hull build time exceeds 20 ms per type, it reports DONE_WITH_CONCERNS — cost if wrong: a slower background worker pre-warm only.
- Task 2: Ruling P2-R4 (amends P2-R3): the physics collider is RAPIER.ColliderDesc.roundConvexHull(s·V, ρ) — the analytic rounded solid that the visual mesh approximates (within 0.01) — with the exact mesh kept for rendering only. Measured whole-throw 30×d20: 68–80 ms (exact mesh hull) → 23–26 ms; fairness is unchanged (full symmetry is kept). chamfer.js exports the Minkowski parameters (no duplicated maths); the hull payload becomes {points, radius}; the coin keeps its cylinder (a roundCylinder if trivial). Why: the spec's 100 ms big-pool visibility target; it matches "physics = what you see" better than the mesh-vertex hull — cost if wrong: none visible.
- Task 2: Ruling: the d10 single-ρ (apex edges 0.034 vs 0.07 bevel) is accepted and added to the Task 9 look sign-off items — cost if wrong: retune at sign-off.
- Ruling P2-R5: Task 4 also keys DiceBox's geometry cache by `type|edges.style` and passes `{ style }` to buildDieGeometry — appearance.edges.style must reach the geometry, and the plan's "call-site only" missed that — cost if wrong: trivial.
- Ruling P2-R6 (look, load-bearing for the default appearance): resin stops using screen-space transmission. On Dicer's transparent overlay canvas the transmission pass has nothing behind the die, so the gallery shows the clear resin dice as dark solids. Resin becomes an environment-refraction material:
- Ruling P2-R7: accept the resin "lit table" floor term (uResinFloor 0.35 for refracted directions below the horizon) and the exit-normal blend (50% sphere normal, 50% mirrored entry face; flattened ellipsoid for the coin) as extensions of P2-R6 — without them resin reads black or shows an orb; both are uniforms/constants tuned in Task 9 — cost if wrong: retune.
- Ruling P2-R8: body.roughness is honoured for every body type. The per-body/finish brief roughness values become the curated looks' values (set in Task 9); the material reads appearance.body.roughness — the schema defines roughness for all bodies, and dead data in LOOKS would mislead Plan 5 themes and Plan 7's editor. Implemented in Task 9 — cost if wrong: trivial.
- Task 6: Ruling: the d20 star smear (refraction through many small facets) is accepted as physically expected; it goes on the Task 9 sign-off list (options there: lower refraction strength or a larger shape on d20) — cost if wrong: one tuning pass.
- Ruling P2-R9: the tier table keeps `transmissionScale` and applyTier still sets renderer.transmissionResolutionScale (harmless), but P2-R6 removed resin transmission, so Review Focus #4 (20 resin dice transmission cost) is moot; Task 7 instead adds a full-screen interior cost probe (the GPU probe renders resin+nebula at the High program into a larger target — 512² — so the per-pixel march cost dominates over draw calls) — cost if wrong: the probe takes a few ms longer.
- Ruling P2-R10 (amends the brief's AdaptiveQuality/frame-time spec): AdaptiveQuality clamps each sample to min(ms, 3×budget) and ignores the first 10 frames after construction, reset(), or a tier change; the frame-time source reports max(CPU tick+render, rAF interval capped at 100 ms), so GPU-bound frames register — EMA seeding as briefed lets one compile hitch cascade drops to low, and CPU submit time misses GPU-bound ray-march load — cost if wrong: slightly slower to react to a real slowdown (10 frames).
- Ruling P2-R11: the quality state splits into adaptiveDrops and shaderForcedLow. A client `quality` setting change resets adaptiveDrops (and adaptive.reset()); a qualityCap change doesn't; shaderForcedLow persists for the session. The adaptive drop is stored as a ceiling (the tier index after the drop), not a subtracted count, so choosing at or below the ceiling gives exactly that tier — a user's explicit choice must not land below what they picked; a failing shader will fail again — cost if wrong: a slow machine re-drops once after a manual change.
- Task 9: Ruling: the low-tier tint keeps body luminance (deviates from the list's linear mix) — the linear mix at any share turned Void Star olive; the per-type shares stand — cost if wrong: low-tier nebula/liquid read closer to plain resin.
- Ruling P2-R12: a shader error at low, or a repeat error, switches to SAFE flags for the session (no engraving, glow, interiors or Dicer body chunks). Dice must always show. Cost if wrong: plain dice on a broken driver.
- Ruling P2-R13: a frame counts as slow only above budget AND 1.3x the median recent rAF interval, using GPU time where available. Battery 30 Hz caps and heavy PIXI scenes are not Dicer's cost. Cost if wrong: slower reaction when the baseline itself is slow.
- Ruling: edges.style is removed from programKey, since no define depends on it. Cost if wrong: none.
- Ruling: sharp-style dice keep the rounded collider, documented. The corner dip is invisible at play size. Cost if wrong: d4 tips dip slightly while tumbling.
- Final: parked: with a GPU timer, P2-R13's interval-baseline gate still stops adaptive drops for a machine that is GPU-bound from its first roll. Ruling: leave as ruled for Plan 2 (the probe tier is the defence); Plan 8 benchmarking should revisit by judging GPU time against the budget alone when a timer exists. Cost if wrong: a slow-from-start machine stays on the probe-picked tier.

- The low-tier tint keeps the body's brightness.
